# IAM Groups

## Objective
Create IAM groups to manage permissions for multiple users efficiently.

---

## Steps Taken

### 1. Open IAM Service
- Logged into AWS Console.
- Navigated to the IAM dashboard.

### 2. Open Groups Section
- Selected **User groups** from the left menu.

### 3. Create a Group
- Clicked **Create group**.
- Entered the group name.

### 4. Attach Permissions
- Selected IAM policies based on required access.
  - Example:
    - AmazonS3ReadOnlyAccess
    - AdministratorAccess

### 5. Add Users to Group
- Selected IAM users to include in the group.

### 6. Create Group
- Reviewed settings.
- Clicked **Create group**.

---

## Result
IAM groups were created to simplify permission management and enforce role-based access control.
