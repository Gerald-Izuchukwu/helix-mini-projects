# AWS IAM Management Lab

## Overview
This project demonstrates basic AWS Identity and Access Management (IAM) concepts, including:

- Creating IAM users
- Creating IAM groups
- Applying the Principle of Least Privilege

The goal is to manage AWS access securely using role-based permissions instead of relying on the root account.

## Objective

The objective of this lab is to:
- Improve AWS account security
- Understand IAM best practices
- Learn how to manage permissions efficiently

---

## Best Practices Followed

- Avoided using the root account for daily tasks
- Used groups to manage permissions
- Assigned only required permissions
- Followed the Principle of Least Privilege

---

## Conclusion

This project provides a foundational understanding of AWS IAM and secure access management practices.
