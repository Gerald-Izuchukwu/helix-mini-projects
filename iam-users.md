# IAM Users

## Objective
Create IAM users in AWS for individual access instead of using the root account.

---

## Steps Taken

### 1. Sign in to AWS Console
- Logged into the AWS Management Console using the root account or an administrator account.

### 2. Navigate to IAM
- Opened the IAM service from the AWS Console.

### 3. Open Users Section
- Selected **Users** from the left navigation pane.

### 4. Create a New User
- Clicked **Create user**.
- Entered the username.
- Enabled AWS Management Console access if console login was required.

### 5. Set User Credentials
- Configured password settings:
  - Auto-generated password OR
  - Custom password

### 6. Assign Permissions
- Added the user to an existing IAM group OR
- Attached policies directly to the user.

### 7. Review and Create
- Reviewed the configuration.
- Clicked **Create user**.

### 8. Save Credentials
- Downloaded or copied the login credentials securely.

---

## Result
IAM users were successfully created for controlled and individual AWS access.
