# Nginx Static Website Hosting

This project demonstrates how to use Nginx to serve a simple static HTML website.

## Project Overview

The website is hosted using:

- **Nginx** as the web server
- A simple HTML file
- Linux server environment

The static webpage contains:

- Name
- Course title
- Welcome message
